Trading never stops — so neither does the agent. A scheduled job (an AWS Lambda on a daily timer) scans each day's new trades, detects fresh rings, and — the key part — ranks them by how closely they match cases already confirmed in memory. The analyst opens a worklist that's already triaged: "this new ring is 99% identical to confirmed case C020 — start here."

What this is. I pulled every LooksRare trade from 2022, built a graph of who-traded-with-whom, and searched for closed loops — clusters of wallets that keep selling the same NFTs back to each other. A genuine sale moves an NFT to a new owner; these loops never do. That's wash trading: manufacturing fake volume to lure real buyers. Each case below is one ring I found — click one.

Why a memory? Real surveillance teams ask, after every incident, "what should we have caught sooner?" This agent turns each confirmed case into a searchable memory in CockroachDB. New activity is compared against that memory by meaning (AWS Bedrock embeddings + vector search), so the agent gets sharper with every verdict.
