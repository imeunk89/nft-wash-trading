- 선례 테이블이 **벡터 인덱스가 실제로 하는 일**입니다. "how the agent handled the most similar cases — vector index" 라벨을 화면에 잡으세요
- baseline 37개 케이스는 이미 확정이라 근거·버튼 대신 "already in memory"가 뜹니다. **반드시 daily-run 링**(예: 2023-02-20-13)을 여세요

## 1:34 – 2:16 · 기억이 학습한다 ★핵심★ (42초)

**화면**
"How the memory learns" 탭. **Next**를 순서대로. 각 단계의 **"Case note being checked"** 박스가 화면에 뜹니다.

1. **Next** → 첫 번째 case note + 미터 **49% match**
2. **Next** → 메모리 선반 +1, 카운터 37 → **38**

**내레이션**

>
> 며칠 뒤, **다른 애널리스트가 같은 조직을 적습니다.** 그런데 자기 말로 씁니다. 화면의 **두 노트를 나란히 보세요 — 겹치는 단어가 거의 없습니다.** '두 개의 새 지갑'과 '형제 지갑 쌍', '같은 부모 주소'와 '하나의 공통 출처'. **키워드 검색이라면 여기서 놓칩니다.**

> 그런데 **63% 일치.** 아까보다 훨씬 가까워졌습니다. **단어가 아니라 의미로 찾았기 때문입니다.** 방금 확정한 노트를 기억하고 있었으니까요.
>
> 반대도 됩니다. 무해한 활동을 오탐했을 때 애널리스트가 '아니다'라고 하면, 다음에 비슷한 노트가 와도 **조용히 넘어갑니다.** 같은 헛알람이 두 번 울리지 않습니다."

**노트**
- 42초로 가장 깁니다. **줄이지 마세요** — 대회 주제가 "Agentic Memory"입니다
- ★**이 섹션의 핵심 시각 자료는 화면의 두 case note 박스입니다.** "Case note being checked"(지금 것)와 "Closest confirmed case"(기억에 있던 것)를 **손으로 짚으면서** "단어가 안 겹치죠?"라고 말하세요. 이게 "semantic 검색"을 말 없이 증명합니다

- **"임베딩", "벡터", "코사인"** 은 말하지 마세요. "단어가 아니라 의미로" 로 충분합니다
- 미터는 **"오른쪽=강한 일치"**. 색·라벨이 화면에 있어 방향 설명 불필요
- **`+14 pts closer` 배지 = 클라이맥스. 3초 정지**

## ⚠️ 절대 말하면 안 되는 것 (사실과 다름)

| ❌ 하면 안 되는 말 | 이유 | ✅ 대신 |
|---|---|---|
| "CockroachDB는 **벡터형 DB**" | 아닙니다. **분산 SQL DB**(Postgres 호환)이고 벡터 인덱싱은 v25.2의 *기능*입니다. 벡터 DB는 Pinecone·Weaviate 계열 | "벡터 인덱싱을 내장한 **분산 SQL 데이터베이스**" |
